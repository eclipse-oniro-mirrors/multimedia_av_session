# 测试与故障诊断

## 测试层次

- 会话项、控制器项、服务、会话栈、焦点、后台音频、多用户和音频设备管理单元测试。
- 投播路由、投播控制器、Cast+ 引擎对接和流播放器单元测试。
- 分布式 Source/Sink、软总线通信和会话迁移（CROSS/NEXT 模式）单元测试。
- IPC 代理/Stub 序列化、权限校验和服务死亡测试。
- 原生客户端、OHAVSession 和内部 API 单元测试。
- 适配层（音频、应用管理、账户、按键、协同、分布式对象、插件库、权限、限流）测试。
- 工具（共享内存、Base64、哈希、雷达、动态加载）测试。
- IPC 入口、序列化、配置解析、回调、服务、控制器、投播、焦点、后台音频、协同、迁移、软总线、权限和监听器模糊测试。

## 故障诊断

- HiLog 提供客户端和服务端结构化日志。
- `hisysevent.yaml` 集中定义 `AV_SESSION` 域诊断事件（服务启动、焦点变化、权限拒绝、命令失败与失败率、命令与会话生命周期统计、投播行为与控制、远程控制失败、错误状态、输入重分发、API 行为等）。
- HiTrace 由 `multimedia_av_session_enable_trace_control` 控制；分布式同步路径保留 Trace 点。
- `AVSessionDumper` 响应 hidumper，支持元数据、会话信息、控制器信息、错误信息和信任设备信息转储，仅在本地调试使用。
- HiCollie 看门狗由 `multimedia_av_session_enable_hicollie` 控制。
- 恢复路径覆盖服务死亡、投播服务死亡、分布式断连、软总线建链重试（5 次/500ms）、迁移心跳和会话栈内存回收。

## 测试不变量

- 每个生命周期操作都应覆盖非法状态和重复调用。
- 每个 IPC 方法都应覆盖空远程对象、非法输入和服务不可用。
- 每类设备事件都应覆盖连接、断开、变化和过期事件。
- 每条隐私敏感链路都应覆盖允许、拒绝、静音和权限撤销。
- 每个功能开关在可行时都应覆盖开启和关闭路径。

## 测试目录

- 服务端单元测试和模糊测试集中在 `services/session/server/test/`。
- 原生客户端和绑定层测试在 `frameworks/native/session/test/`、`frameworks/native/ohavsession/test/` 和 `interfaces/inner_api/native/session/test/`。
- 测试资源在 `test/resource/`。
