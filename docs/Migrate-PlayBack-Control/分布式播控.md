# 分布式播控

## 范围

分布式播控负责组网内设备之间的会话同步和控制能力，采用 Source/Sink 双端模型 + 会话同步器 + 软总线通信架构，并辅以会话迁移机制，支持 MigrateWithNext（手机↔手表）和 SuperLauncher（多设备协同流转）两种场景。本地会话与焦点见[基础播控.md](../Basic-PlayBack-Control/基础播控.md)，投屏投音的 Cast+ 引擎路由见[音视频投播.md](../AV-BroadCast/音视频投播.md)。分布式数据对象同步（remote）和软总线通信（softbus）是两个不同通道，前者用于 Source/Sink 状态同步，后者用于迁移数据传输。

## 功能规格

- Source 端投射会话到远端、同步本地会话信息（元数据/播放状态/队列/事件/扩展）、处理远端回传控制与通用命令、取消投射。
- Sink 端接收远端会话、同步六类远端数据、反向发送控制与通用命令。
- 会话同步器基于分布式数据对象实现两端状态一致，含键名常量、SHA256 对象名和大小上限。
- 能力集管理收集本地能力、记录远端能力、按掩码查询过滤，仅同步远端支持字段。
- JSON 工具完成能力集、会话基本信息和会话描述符的序列化。
- 远程命令处理经跨设备 RPC 转发投播命令。
- 软总线通信负责会话建立（Socket/Bind/Listen）、QoS、失败重试和数据传输（定向/广播/Next 专用/消息）。
- 软总线代理/服务端模式按 characteristic 路由，动态加载软总线 C 接口。
- 会话迁移 CROSS 模式（SuperLauncher）同步多会话、控制器列表/历史和心跳。
- 会话迁移 NEXT 模式（MigrateWithNext）同步前台会话元数据/播放状态/媒体图片/bundle 图标/有效命令，含长暂停检测、音量/设备/协议版本同步和心跳。
- 迁移管理单例通过引用计数控制软总线 server 生命周期，创建和释放本地 stub/远端 proxy。

## 约束

- 分布式数据对象同步（remote）和软总线通信（softbus）是两个不同通道，不可混淆：前者用于 Source/Sink 会话状态同步，后者用于会话迁移数据传输。
- 功能开关保护：`multimedia_av_session_enable_data_object` 控制分布式数据对象同步，`av_session_enable_dsoftbus` 控制软总线和迁移；关闭后不能破坏基础会话路径，依赖缺失时降级。
- Source/Sink 配对：两端用相同输入（sourceSessionId + sourceDevice + sinkDevice）经 SHA256 算出相同对象名连接同一分布式对象；对象名不匹配会导致同步失败。
- 单条数据上限 `RECEIVE_DATA_SIZE_MAX = 500KB`，超限拒绝；序列化用 Marshalling → 字节流写入，反序列化用 ParseFrom 还原。
- 能力集掩码过滤：Source 端基于远端能力集生成掩码，仅同步远端支持字段。
- 软总线会话名固定为 `Media_Session_RemoteCtrl`，QoS 最小带宽 64k、最大建链时延 19s、最小建链时延 0.5s；建链失败重试 5 次间隔 500ms。
- 一个 networkId 可有多个 proxy（不同 characteristic）共享一个 socket；车机 A2DP 在线时不发送。
- 迁移模式常量属协议契约：`MSG_HEAD_MODE=100`（CROSS/SuperLauncher）、`MSG_HEAD_MODE_FOR_NEXT=101`（NEXT/MigrateWithNext），`data[0]` 区分模式，`data[1]` 为命令类型，`data[2:]` 为负载。
- 迁移心跳：CROSS 180s，NEXT 30s/3600s + 连接检查 5s；长暂停检测 5 分钟通知手表。
- 引用计数控制软总线 server 生命周期：归零时初始化 server，归零时销毁 server。
- 跨设备 RPC 仅限 `SERVICE_CMD_SEND_COMMAND_TO_REMOTE`，其余接口仅本地。
- 迁移 JSON 协议（能力集、会话基本信息、会话描述符、控制命令）和 Base64 二进制兼容属跨版本协议，修改需评估兼容性。

## 安全与隐私

- 远端设备授权和网络标识（networkId、deviceId）属设备隐私，能力集交换和会话同步需校验对端身份，无法确认时失败关闭。
- Source 端仅同步远端支持的字段（掩码过滤），不泄露远端不支持或不必要的元数据；回调载荷只应包含接口契约要求的信息。
- 媒体图片同步经 JPEG 压缩 + Base64，避免传输原始像素图。
- 控制命令反向同步（Sink → Source）需校验命令有效性和会话状态，过期回调不可重新唤醒已停止会话。
- 分布式断连时触发断连通知，上报 `REMOTE_CONTROL_FAILED` 并清理同步器、软总线 Socket 和迁移 Proxy/Server。
- Source 代理经 dlopen 动态加载并防 CFI，调用加 Trace 追踪。
- 禁止日志包含 PCM 内容、媒体元数据原始令牌、远端网络标识、设备地址和未脱敏应用数据。
- 迁移涉及真实设备和组网，修改前必须说明影响范围并等待确认，不得执行未经确认的破坏性命令。

## 源码入口

- 分布式数据对象同步：`RemoteSessionSource` / `RemoteSessionSourceImpl` / `RemoteSessionSourceProxy` / `RemoteSessionSink` / `RemoteSessionSinkImpl` / `RemoteSessionSyncer` / `RemoteSessionSyncerImpl` / `RemoteSessionCommandProcess` / `RemoteSessionCapabilitySet` / `JsonUtils`
- 软总线通信：`SoftbusSession` / `SoftbusSessionManager` / `SoftbusSessionManagerDynamic` / `SoftbusSessionProxy` / `SoftbusSessionServer` / `SoftbusDistributedDataManager`
- 会话迁移：`MigrateAVSessionManager` / `MigrateAVSessionServer`（含 Next 变体）/ `MigrateAVSessionProxy`（含 Super 变体）/ 迁移命令常量
- 适配层：`DistributedObjectAdapter`
- 服务集成入口：`AVSessionService` 扩展（SuperLauncher/MigrateWithNext/设备状态回调）
- 协议枚举：`SessionDataCategory` / `RemoteServiceCommand` / `AVSessionBasicInfo` / `IAncoMediaSessionListener` IDL
