# 播控安全与隐私

## 信任边界

- 应用到框架绑定（NAPI/CJ/Taihe/OHAVSession）。
- 原生客户端代理到系统能力代理。
- IPC 代理到服务端 Stub。
- 服务端到适配层（音频、应用管理、账户、按键、协同、分布式对象、插件库）。
- 播控服务到 Cast+ 引擎、软总线、分布式数据对象、协同服务库和设备管理。
- 配置文件、参数访问控制和插件加载边界。

## 必要控制

- 对系统操作、媒体资源管理和媒体资源公共操作执行调用方身份及权限校验；`PermissionChecker` 是校验入口。
- 校验所有序列化输入、字符串、枚举、长度、会话标识、UID、PID、令牌 ID 和远程对象。
- 会话创建校验参数、纠正三方调用者 element、同 pid 唯一会话；投播 castHandle 编解码必须一致，反解失败应拒绝。
- 跨服务调用时正确保存和恢复 IPC 调用身份。
- Stub 校验本地调用，除投播命令转发外禁止跨设备 RPC。
- 会话数据使用有界缓冲区和安全内存操作；分布式数据对象单条上限 500KB，回调 IPC 容量受限。
- 服务死亡和回调注销过程中不产生悬空对象、重复回调或过期状态。
- 日志不能包含原始 PCM、媒体元数据令牌、设备地址、网络标识和未脱敏身份。

## 隐私敏感功能

- 会话元数据（标题、艺术家、专辑、媒体图像、歌词）和应用包名/Ability 属应用隐私。
- 设备信息（deviceId、networkId、ipAddress、bleMac、uuid、realDeviceId）和远端授权状态属设备隐私。
- 后台音频静音状态和用户选择属应用行为隐私。
- 分布式会话同步和能力集掩码过滤涉及跨设备数据共享，必须按远端能力仅同步支持字段。
- 投播设备选择和音量面板涉及用户交互选择。
- 账户相关会话栈、TopSession 和持久化历史记录属账户隐私。
- 通话元数据（电话号码、通话状态）属高度敏感数据。

## 日志与诊断约束

- `hisysevent.yaml` 定义诊断事件，SECURITY 级别事件记录调用方 UID/PID、会话 ID、包名、按键码和命令。
- FAULT 级别事件记录错误类型、命令、调用方 PID 和错误码，不记录敏感载荷。
- Dump 输出仅在本地调试使用，不应输出到无关进程。

## 失败策略

当无法确认权限、输入合法性、设备可用性、远端能力或服务可用性时，应失败关闭，返回稳定错误码（`AVSessionErrorCode`，6600101-6600107），并保持已有会话和控制器状态不变。分布式断连时上报 `REMOTE_CONTROL_FAILED` 并清理同步器、软总线 Socket 和迁移 Proxy/Server；投播服务死亡时清理 Provider 会话和控制器映射。
