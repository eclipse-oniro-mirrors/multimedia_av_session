# 播控安全与隐私

## 信任边界

- 应用到框架绑定（NAPI/CJ/Taihe/OHAVSession）。
- 原生客户端代理（`frameworks/native/session/`）到系统能力代理（`services/session/ipc/proxy/`）。
- IPC 代理到服务端 Stub（`services/session/ipc/stub/`）。
- 服务端到适配层（`services/session/adapter/`）：音频、应用管理、账户、按键、协同、分布式对象、插件库。
- 播控服务到 Cast+ 引擎、软总线、分布式数据对象、协同服务库和设备管理。
- 配置文件、参数访问控制（`services/etc/avsession.para.dac`）和插件加载边界。

## 必要控制

### 权限校验

- `PermissionChecker`（`utils/include/permission_checker.h`）是权限校验入口，单例。
- 校验类型：`CHECK_SYSTEM_PERMISSION`、`CHECK_MEDIA_RESOURCES_PERMISSION`、`CHECK_MEDIA_RESOURCES_PUBLIC_PERMISSION`、`CHECK_SYSTEM_AND_MEDIA_RESOURCES_PUBLIC_PERMISSION`。
- 权限名：`ohos.permission.MANAGE_MEDIA_RESOURCES`、`ohos.permission.MANAGE_MEDIA_RESOURCES_FOR_PUBLIC`。
- Stub 层每个 Handle 方法均经 `PermissionChecker::CheckPermission` 校验；校验失败返回 `AVSESSION_ERROR` 并上报 `CONTROL_PERMISSION_DENIED`（SECURITY 级别）。
- `CheckSystemPermissionByUid` 通过 UID（除以 `UID_TRANSFORM_DIVISOR=200000`）判断系统应用。

### 输入校验

- 校验所有序列化输入、字符串、枚举、长度、会话标识、UID、PID、令牌 ID 和远程对象。
- 会话创建校验 `IsParamInvalid`（tag/type/elementName）、`CorrectElementForThirdPartyCaller`（纠正三方调用者 element）、`AbilityHasSession`（同 pid 唯一会话）。
- 投播 castHandle 编解码必须一致，反解失败应拒绝。
- 分布式数据对象单条数据上限 `RECEIVE_DATA_SIZE_MAX = 500KB`，超限拒绝。
- 控制器回调 IPC 容量 `ipcincapacity 1024`；投播控制器代理默认 1MB。

### 调用身份与跨设备 RPC

- 跨服务调用时正确保存和恢复 IPC 调用身份。
- Stub `OnRemoteRequest` 校验 `IsLocalCalling()`，除 `SERVICE_CMD_SEND_COMMAND_TO_REMOTE` 外禁止跨设备 RPC。
- 跨设备 RPC 仅限投播命令转发，其余接口仅本地调用。
- 会话数据使用有界缓冲区和安全内存操作。

## 隐私敏感功能

- 会话元数据（标题、艺术家、专辑、媒体图像、时长、歌词等）和应用包名/Ability 属于应用隐私，回调载荷只应包含接口契约要求的信息。
- 设备信息（deviceId、networkId、ipAddress、bleMac、uuid、realDeviceId）和远端设备授权状态属于设备隐私，不得泄露给无关应用。
- 后台音频静音状态和用户选择属于应用行为隐私。
- 分布式会话同步和能力集掩码过滤涉及跨设备数据共享，必须按远端能力集仅同步支持字段。
- 投播设备选择（AVCastPicker）和音量面板涉及用户交互选择。
- 账户相关会话栈、TopSession 和持久化历史记录（`/data/service/el2/<userId>/av_session/`）属于账户隐私。
- 通话元数据（电话号码、通话状态）属于高度敏感数据。

## 日志与诊断约束

- 禁止新增包含 PCM 内容、媒体元数据原始令牌、设备地址、远端网络标识、bleMac、uuid 或未脱敏应用数据的日志。
- `hisysevent.yaml` 定义诊断事件，SECURITY 级别事件 `CONTROL_PERMISSION_DENIED` 记录调用方 UID/PID、会话 ID、包名、按键码和命令。
- FAULT 级别事件 `CONTROL_COMMAND_FAILED`、`REMOTE_CONTROL_FAILED`、`AVSESSION_WRONG_STATE` 记录错误类型、命令、调用方 PID 和错误码，不记录敏感载荷。
- Dump 输出（`AVSessionDumper`）仅在本地调试使用，不应输出到无关进程。

## 失败策略

当无法确认权限、输入合法性、设备可用性、远端能力或服务可用性时，应失败关闭：

- 返回稳定错误码（见 `AVSessionErrorCode`，6600101-6600107）。
- 保持已有会话和控制器状态不变，不产生悬空对象、重复回调或过期状态。
- 服务死亡和回调注销过程中清理监听器和远程对象引用。
- 分布式断连时上报 `REMOTE_CONTROL_FAILED` 并清理 Syncer、软总线 Socket 和迁移 Proxy/Server。
- 投播服务死亡（`OnCastServerDied`）时清理 Provider 会话和控制器映射。
