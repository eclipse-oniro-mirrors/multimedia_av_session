# 基础播控

## 范围

基础播控负责本地音视频会话的创建、管理、控制和状态同步，包括会话生命周期、控制器、焦点策略、后台音频控制、多用户隔离、音频设备管理和 IPC 通信。投播路由与 Cast+ 引擎对接见[音视频投播.md](../AV-BroadCast/音视频投播.md)，组网内 Source/Sink 同步与软总线迁移见[分布式播控.md](../Migrate-PlayBack-Control/分布式播控.md)。

## 功能规格

- 会话创建、激活、停用和销毁的全生命周期管理，含会话描述符、元数据、播放状态、队列、扩展和会话事件。
- 控制器创建并绑定会话，转发控制命令、按键事件和通用命令，按掩码增量同步元数据与播放状态。
- 会话栈容器的增删查、排序、上限校验和内存回收。
- 焦点策略监听音频渲染状态、选择 TopSession、延迟停止和会话栈排序。
- 后台音频控制对无会话的三方后台应用静音、前台恢复并校验是否持有会话。
- 多用户隔离按用户分隔会话栈与 TopSession，处理账户切换和车机多音区。
- 音频设备管理监听输出设备变化和插拔，配合迁移切换本地与远端输出。
- IPC 采用 Proxy/Stub 模式，维护服务、会话、控制器接口码、回调 IDL 和本地调用约束。
- 提供多语言绑定（NAPI、C 接口、CJ、Taihe、OHAVSession）和调试转储。

## 约束

- 会话必须遵循创建、激活、运行、停用、销毁的状态机；销毁后控制器不可用，回调不可重新唤醒已停止或释放的会话。
- 同一 pid 同一 ability 仅允许一个会话，重复创建返回 `ERR_SESSION_IS_EXIST`；会话总数上限 `SESSION_NUM_MAX=50`，超限返回 `ERR_SESSION_EXCEED_MAX`。
- 会话栈空时延迟 240s 写 `/proc/<pid>/reclaim` 触发内核内存回收，修改容器逻辑不得破坏上限和回收。
- 焦点决策对同一组活动会话应保持确定性；新进入播放触发焦点更新，停止延迟 5s 后通知，期间恢复则取消。
- TopSession 变化需通知所有监听器并镜像到投播场景。
- 后台音频静音仅针对无会话的三方后台应用，前台恢复时解除静音，并通过会话持有校验避免误静音。
- 多用户隔离：每用户独立会话栈与 TopSession，目录 `/data/service/el2/<userId>/av_session/`；账户切换或移除时清理。
- 控制命令分发需校验会话状态、命令有效性和调用方身份；元数据/播放状态按掩码增量同步，仅传递变更字段。
- IPC 只有 `SERVICE_CMD_SEND_COMMAND_TO_REMOTE` 允许跨设备 RPC，其余仅本地调用；接口码与序列化顺序属兼容性契约。
- 控制器元数据回调 IPC 容量 `ipcincapacity 1024`，序列化不得突破边界。

## 安全与隐私

- Stub 层每个 Handle 方法经权限校验，失败返回错误码并上报 `CONTROL_PERMISSION_DENIED`。
- 会话创建校验参数、纠正三方调用者 element、同 pid 唯一会话。
- 元数据（标题、艺术家、专辑、媒体图像、歌词）、包名/Ability、通话元数据（电话号码）属应用隐私，回调载荷只应包含接口契约要求的信息。
- 不得向一个应用泄露无关应用的包名、会话和状态等非必要信息。
- 设备信息（deviceId、networkId、ipAddress）属设备隐私，本地输出设备变更回调不暴露给无关应用。
- 禁止日志包含 PCM 内容、媒体元数据原始令牌、设备地址和未脱敏应用数据。
- 无法确认权限、输入合法性或服务可用性时失败关闭，返回稳定错误码并保持已有会话和控制器状态不变。

- 服务端：`AVSessionService` / `AVSessionItem` / `AVControllerItem` / `SessionStack` / `FocusSessionStrategy` / `BackgroundAudioController` / `AVSessionUsersManager` / `AudioDeviceManager` / `AVSessionDumper`
- 客户端代理：`AVSessionManagerImpl` / `AVSessionServiceProxy` / `AVSessionServiceStub` / `IAVSessionService` / 接口码定义
