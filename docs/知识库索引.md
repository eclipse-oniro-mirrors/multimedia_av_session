## 三大模块

播控框架围绕三大模块组织，修改前必须确认任务所属模块和涉及的跨模块边界：

| 模块 | 职责 | 关键目录 |
| --- | --- | --- |
| 基础播控 | 本地音视频会话的创建、管理、控制和状态同步 | `services/session/server/`（会话项、控制器项、会话栈、焦点、后台音频、多用户） |
| 音视频投播 | 将本地媒体投播到远端设备（投屏、投音） | `services/session/server/`（AVRouter、HwCastProvider、AVCastControllerItem、PcmCastSession）、`services/session/adapter/`（协同） |
| 分布式播控 | 组网内设备间的会话同步、迁移和控制 | `services/session/server/remote/`、`softbus/`、`migrate/` |

## 跨模块不变量

- 会话必须遵循创建、激活、运行、停用、销毁的生命周期；控制器绑定会话，会话销毁后控制器不可用。
- 焦点策略必须同时考虑音频渲染状态、流用途、应用身份和会话栈顺序；TopSession 变化需通知所有监听器并镜像到投播/分布式场景。
- 投播路由 castHandle 编码为 `(providerId << 32) | castId`，编解码必须保持一致；AVRouter 管理路由，AVCastControllerItem 管理控制命令转发，两者不可混淆。
- 分布式数据对象同步单条数据上限 500KB；软总线建链失败重试 5 次/500ms；迁移心跳间隔 CROSS 180s / NEXT 30s/3600s。
- IPC 边界必须校验远程对象、序列化数据、会话标识、调用方身份和服务死亡状态；只有 `SERVICE_CMD_SEND_COMMAND_TO_REMOTE` 允许跨设备 RPC。
- 可选功能必须由对应功能开关保护，关闭后不能破坏基础会话、控制器、投播和分布式路径。
- 日志和诊断不能暴露 PCM 内容、媒体元数据原始令牌、设备地址、远端网络标识和未脱敏应用数据。
