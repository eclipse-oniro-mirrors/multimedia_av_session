# 音视频投播模块

## 模块概述

音视频投播模块实现将本地媒体投播到远端设备（投屏到电视、投音到音箱）的能力。通过 AVRouter 管理投播路由，AVCastController 控制远端播放，HwCastProvider 对接 Cast+ 引擎，并支持 PCM 音频投播、HiPlay/URLCasting 协同等场景。

## 范围

音视频投播覆盖以下能力：

- 投播设备发现、可发现性设置和发现停止。
- 投播路由：castHandle 编解码 `(providerId << 32) | castId`、单 Provider 多会话机制、StartCast/AddDevice/StopCast。
- 投播控制器：控制命令转发、Start/Prepare、状态回调过滤、有效命令变化、销毁。
- Cast+ 引擎对接：HwCastProvider 设备发现与会话创建、HwCastProviderSession 设备状态/事件/HiPlay 事件、HwCastStreamPlayer 流播放器与状态映射。
- PCM 投播：PcmCastSession 命令映射、流播放器创建/释放、HiPlay 超时（30 分钟）。
- HiPlay/URLCasting 协同：CollaborationManager 动态加载协同服务库、设备判定、投播模式切换。
- 数据源：HwCastDataSourceDescriptor（ICastDataSource）、AVFileDescriptor、AVDataSrcDescriptor。
- 显示监听：HwCastDisplayListener 屏幕连接/断开/扩展屏。
- 投播 UI 组件：AVCastPicker、AVInputCastPicker、NapiAVCastPickerHelper。
- 多语言绑定：NAPI（NapiAVCastController）、C 接口（OH_AVCastController_*）、OHAVCastController、C 设备信息接口。
- IPC：IAVCastController 接口码、AVCastControllerProxy（默认 1MB）/Stub、IAVCastControllerCallback IDL。

不在此模块：本地会话与焦点（见[基础播控.md](../Basic-PlayBack-Control/基础播控.md)）、组网内 Source/Sink 同步与软总线迁移（见[分布式播控.md](../Migrate-PlayBack-Control/分布式播控.md)）。AVRouter 通过 `CreateSessionByCast` 接入基础播控服务。

## 投播路由机制

AVRouter 采用 **单 Provider + 多会话** 的路由机制：

1. **初始化**（`avrouter_impl.cpp:52`）：创建唯一 `HwCastProvider`，注册为 providerNumber_=1
2. **castHandle 编码**（`avrouter_impl.cpp:284`）：`castHandle = (providerId << 32) | castId`，前32位标识 Provider，后32位标识会话
3. **投播启动**（`avrouter_impl.cpp:409` `StartCast`）：设 castSide_=CAST_SOURCE → 获取 Provider → `provider->StartCastSession(protocol, isPcm)` → 组装 castHandle
4. **设备连接**（`avrouter_impl.cpp:455` `AddDevice`）：反解 castHandle → `provider->AddCastDevice(castId, deviceInfo, spid)`
5. **控制器获取**（`avrouter_impl.cpp:382` `GetRemoteController`）：反解 castHandle → 缓存查找或 `provider->GetRemoteController(castId)`
6. **状态回调分发**（`avrouter_impl.cpp:857` `OnCastStateChange`）：遍历 castHandleToInfoMap_，异步投递状态变化

## 约束

- castHandle 编码 `(providerId << 32) | castId`，编解码必须保持一致；反解失败应拒绝，不可混淆不同 Provider 的会话。
- AVRouter 负责路由和 castHandle 管理，AVCastControllerItem 负责控制命令转发和状态回调，两者不可混为同一层。
- 投播控制器生命周期：创建时绑定 castControllerProxy 并注册为 ProxyListener；销毁时反注册监听、置空代理和回调、设 `isSessionCallbackAvailable_=false`。
- 播放状态过滤用 `castPlaybackMask_` + `CopyToByMask` 选择性传递；有效命令变化通过 `HandleCastValidCommandChange` 转发，避免无效状态回传应用。
- 数据源类型判定（`GetSourceType`）区分 PCM/DATASRC/URI/FD，不同类型走不同加载路径，不可混用。
- PCM 投播以 `isPcm=true` 标记，sessionId 为 "pcmCastSession"；HiPlay 超时 30 分钟。
- Cast+ 引擎状态映射表（castPlusStateToString_/castPlusSpeedToDouble_/castPlusLoopModeToInt_）属兼容性契约，新增状态需双向映射。
- IAVCastController 命令码和 IAVCastControllerCallback IDL 方法顺序属兼容性契约，不可复用不兼容接口码。
- 投播控制器代理默认 IPC 容量 1MB，回调 `OnMediaItemChange`/`OnKeyRequest` 为 `ipcincapacity 1024`，序列化不得突破边界。
- CollaborationManager 调用经 PluginLib 动态加载协同服务库，回调超时 10s、用户回调超时 60s；依赖缺失时降级。
- AVCastPicker 经 UIExtensionComponent 连接 `com.hmos.mediacontroller`，样式和状态枚举属 UI 契约。

## 安全与隐私

- 投播涉及远端设备授权和 Cast+ 引擎权限，Stub 层校验调用方身份；跨设备 RPC 仅限 `SERVICE_CMD_SEND_COMMAND_TO_REMOTE`。
- 设备信息（deviceId、networkId、ipAddress、bleMac、uuid、realDeviceId、manufacturer、model）属于设备隐私，不得泄露给无关应用。
- DRM 密钥请求/响应（`OnKeyRequest`/`ProcessMediaKeyResponse`）属敏感数据，回调 IPC 容量受 1024 约束，禁止日志记录密钥内容。
- 媒体描述（mediaId、mediaUri、fdSrc、dataSrc、pcmSrc、drmScheme、launchClientData）属应用媒体隐私，按不可信输入校验。
- HiPlay 设备信息（supportCastMode、castMode、castUid、moduleId、submoduleId）和投播模式切换属设备协同隐私。
- CollaborationManager 申请远端资源时校验 peerNetworkId 和设备授权，无法确认时失败关闭。
- 禁止日志包含 PCM 内容、媒体元数据原始令牌、设备地址、bleMac、uuid 和未脱敏应用数据。
- 投播服务死亡（`OnCastServerDied`）时清理 Provider 会话和控制器映射，失败关闭并保留本地会话状态。
