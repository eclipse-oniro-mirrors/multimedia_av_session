# 音视频投播

## 范围

音视频投播负责将本地媒体投播到远端设备（投屏到电视、投音到音箱），包括投播路由、Cast+ 引擎对接、投播控制器、PCM 投播、HiPlay/URLCasting 协同和投播 UI 组件。本地会话与焦点见[基础播控.md](../Basic-PlayBack-Control/基础播控.md)，组网内 Source/Sink 同步与软总线迁移见[分布式播控.md](../Migrate-PlayBack-Control/分布式播控.md)。投播路由通过接入基础播控服务创建会话。

## 功能规格

- 投播设备发现、可发现性设置和发现停止。
- 投播路由管理 castHandle 编解码、单 Provider 多会话机制、投播启动、设备连接和停止。
- 投播控制器转发控制命令、Start/Prepare、状态回调过滤、有效命令变化和销毁。
- Cast+ 引擎对接负责设备发现、会话创建、设备状态/事件/HiPlay 事件回调和流播放器状态映射。
- PCM 投播处理命令映射、流播放器创建/释放和 HiPlay 超时（30 分钟）。
- HiPlay/URLCasting 协同通过动态加载协同服务库实现设备判定和投播模式切换。
- 数据源支持描述符、文件描述符和数据源描述符，按 PCM/DATASRC/URI/FD 区分加载路径。
- 显示监听负责屏幕连接/断开/扩展屏。
- 投播 UI 组件经 UIExtension 连接播控中心，支持设备列表展示、全屋音乐分区控制和模式切换。
- 提供多语言绑定（NAPI、C 接口、OHAVCastController、C 设备信息接口）和 IPC（接口码、代理/Stub、回调 IDL）。

## 约束

- castHandle 编码为 `(providerId << 32) | castId`，编解码必须保持一致；反解失败应拒绝，不可混淆不同 Provider 的会话。
- 投播路由负责路由和 castHandle 管理，投播控制器负责控制命令转发和状态回调，两者不可混为同一层。
- 投播控制器创建时绑定代理并注册为监听者；销毁时反注册监听、置空代理和回调。
- 播放状态按掩码选择性传递，有效命令变化过滤后转发，避免无效状态回传应用。
- 数据源类型判定区分 PCM/DATASRC/URI/FD，不同类型走不同加载路径，不可混用。
- PCM 投播以标记区分，HiPlay 超时 30 分钟。
- Cast+ 引擎状态映射表属兼容性契约，新增状态需双向映射。
- 投播控制器命令码和回调 IDL 方法顺序属兼容性契约，不可复用不兼容接口码。
- 投播控制器代理默认 IPC 容量 1MB，回调 IPC 容量 `ipcincapacity 1024`，序列化不得突破边界。
- 协同管理经插件库动态加载协同服务库，回调超时 10s、用户回调超时 60s；依赖缺失时降级。

## 安全与隐私

- 投播涉及远端设备授权和 Cast+ 引擎权限，Stub 层校验调用方身份；跨设备 RPC 仅限投播命令转发。
- 设备信息（deviceId、networkId、ipAddress、bleMac、uuid、realDeviceId、manufacturer、model）属设备隐私，不得泄露给无关应用。
- DRM 密钥请求/响应属敏感数据，回调 IPC 容量受限，禁止日志记录密钥内容。
- 媒体描述（mediaId、mediaUri、fdSrc、dataSrc、pcmSrc、drmScheme、launchClientData）属应用媒体隐私，按不可信输入校验。
- HiPlay 设备信息和投播模式切换属设备协同隐私。
- 协同管理申请远端资源时校验对端网络标识和设备授权，无法确认时失败关闭。
- 禁止日志包含 PCM 内容、媒体元数据原始令牌、设备地址、bleMac、uuid 和未脱敏应用数据。
- 投播服务死亡时清理 Provider 会话和控制器映射，失败关闭并保留本地会话状态。

## 源码入口

- 接口层：`AVRouter` / `AVCastController` / `AVCastProvider`
- 服务端：`AVRouterImpl` / `AVCastProviderManager` / `AVCastControllerItem` / `PcmCastSession`
- Cast+ 引擎对接：`HwCastProvider` / `HwCastProviderSession` / `HwCastStreamPlayer` / `HwCastDataSourceDescriptor` / `HwCastDisplayListener`
- 协同适配：`CollaborationManager` / `CollaborationManagerHiPlay` / `CollaborationManagerURLCasting`
- IPC：`IAVCastController` / `AVCastControllerProxy` / `AVCastControllerStub` / `IAVCastControllerCallback` IDL
- 数据结构：`AVCastControlCommand` / `AVCastPlayerState` / `DeviceInfo` / `OutputDeviceInfo` / `AVMediaDescription` / `AVCallMetaData` / `AVCallState` / `AVQueueItem` / `AVQueueInfo` / `AVFileDescriptor` / `AVDataSrcDescriptor`
- UI 组件：`AVCastPicker` / `AVInputCastPicker` / `NapiAVCastPickerHelper`
- 绑定：`NapiAVCastController` / `OHAVCastController` / C 接口
