# 播控框架目录结构说明

下表说明本仓库主要目录及其子目录职责。测试目标数量较多，按目标族归纳；每个具体模糊测试目录通常都包含独立的 GN 目标、测试入口和可选工程元数据。

## 根目录

| 目录 | 简要说明 |
| --- | --- |
| `docs/` | 播控框架知识库，主题文档和索引入口。 |
| `figures/` | 架构图和文档图片。 |
| `frameworks/` | 面向客户端的框架实现和多语言绑定。 |
| `interfaces/` | 公共 Kit（C 接口）和内部 API（C++ 头文件）声明。 |
| `sa_profile/` | 播控系统能力注册配置（SAID=3010）。 |
| `services/` | 播控系统服务核心实现、IPC、适配和配置。 |
| `test/` | 测试资源。 |
| `tools/` | AVSession 管理工具。 |
| `utils/` | 公共工具库（日志、Trace、权限、事件、定时器等）。 |
| `avpicker/` | 投播设备选择 UI 组件（AVCastPicker）。 |
| `avinputcastpicker/` | 通话输入设备投播选择 UI 组件（AVInputCastPicker）。 |
| `avvolumepanel/` | 音量面板 UI 组件。 |

## frameworks

| 目录 | 简要说明 |
| --- | --- |
| `frameworks/common/` | 跨框架公共代码；`src/` 放实现。 |
| `frameworks/cj/` | CJ 语言 FFI 绑定；`include/` 放导出声明，`src/` 放绑定实现，`libcj_multimedia_avsession_ffi.map` 为符号导出策略。 |
| `frameworks/js/` | JavaScript/N-API 实现。 |
| `frameworks/js/napi/session/` | 会话、控制器、投播控制器、管理器、监听器、回调、元数据、播放状态、队列、媒体描述和投播选择器绑定；`include/` 放头文件，`src/` 放实现。 |
| `frameworks/native/` | 原生 C++ 框架实现。 |
| `frameworks/native/session/` | 原生会话客户端代理；`avsession_manager_impl` 为管理类门面，`avsession_callback_client`/`avcontroller_callback_client`/`avcast_controller_callback_client` 为回调客户端，`session_listener_client` 为监听器客户端；`avsession_client.versionscript` 约束符号导出；`test/` 放单元测试。 |
| `frameworks/native/ohavsession/` | OHAVSession C++ 封装（OH_AVSession/OHAVSession/OHAVCastController/OHAVMediaDescriptionBuilder 等）；`include/` 放头文件，`src/` 放实现，`test/` 放测试。 |
| `frameworks/taihe/` | Taihe 绑定；`idl/` 放 IDL，`include/` 放声明，`src/` 放实现。 |

### 服务端（services/session/server）

| 目录/文件 | 简要说明 |
| --- | --- |
| `avsession_service.cpp/.h` | 系统服务主类（SAID=3010），承载会话管理、TopSession、投播接入和分布式集成。 |
| `avsession_service_ext.cpp` | SuperLauncher/MigrateWithNext 集成入口和设备状态回调。 |
| `avsession_item.cpp/.h` | 会话项服务端实现（生命周期、命令分发、按键分发）。 |
| `avcontroller_item.cpp/.h` | 控制器项服务端实现（命令转发、状态/元数据过滤）。 |
| `session_stack.cpp/.h` | 会话栈容器（增删查、排序、内存回收）。 |
| `session_container.h` | 会话容器抽象（`SESSION_NUM_MAX=50`）。 |
| `focus_session_strategy.cpp/.h` | 焦点策略（音频渲染监听、TopSession 选择、延迟停止 5s）。 |
| `background_audio_controller.cpp/.h` | 后台音频控制（无会话后台应用静音、前台恢复）。 |
| `avsession_users_manager.cpp/.h` | 多用户管理（按 userId 隔离会话栈、账户切换、车机多音区）。 |
| `audio_device_manager.cpp/.h` | 音频设备管理（首选输出设备监听、设备插拔、迁移输出切换）。 |
| `avsession_dumper.cpp/.h` | 调试信息转储。 |
| `avsession_whitelist_config_manager.cpp/.h` | 白名单配置管理。 |
| `avsession_item_extension.h` | 会话项扩展接口。 |
| `avrouter.cpp` / `avrouter_impl.cpp/.h` | 投播路由器（GetInstance 工厂）和实现（castHandle 编解码、Provider 管理）。 |
| `avcast_provider_manager.cpp/.h` | 投播提供者管理器（Cast+ 引擎状态监听转发）。 |
| `avcast_controller_item.cpp/.h` | 投播控制器服务端（命令转发、状态回调过滤）。 |
| `hw_cast_provider.cpp/.h` | 华为投播提供者（Cast+ 引擎对接、设备发现、会话创建）。 |
| `hw_cast_provider_session.cpp/.h` | 投播会话（ICastSessionListener、设备状态、事件、HiPlay 事件）。 |
| `hw_cast_stream_player.cpp/.h` | 流式播放器（IStreamPlayerListener、状态映射、命令转换）。 |
| `hw_cast_data_source_descriptor.cpp/.h` | Cast+ 数据源描述符（ICastDataSource）。 |
| `hw_cast_display_listener.cpp/.h` | 显示监听器（屏幕连接/断开/扩展屏）。 |
| `pcm_cast_session.cpp/.h` | PCM 投播会话（命令映射、HiPlay 超时）。 |
| `remote/` | 分布式数据对象同步（Source/Sink/Syncer/CapabilitySet/JsonUtils/CommandProcess）。 |
| `softbus/` | 软总线通信（Session/Manager/ManagerDynamic/Proxy/Server/DistributedDataManager）。 |
| `migrate/` | 会话迁移（Manager/Server/ServerForNext/Proxy/ProxyForSuper/Constant/Base64Utils）。 |
| `test/` | 服务端单元测试和模糊测试。 |
| `test/fuzztest/` | 按适配、服务、控制器、投播、焦点、后台音频、协同、迁移、软总线、权限划分的模糊测试目标。 |
