# 播控框架目录结构说明

下表说明本仓库主要目录及其子目录职责。测试目标数量较多，按目标族归纳；每个具体模糊测试目录通常都包含独立的 GN 目标、测试入口和可选工程元数据。

## 根目录

| 目录 | 简要说明 |
| --- | --- |
| `docs/` | 播控框架知识库，主题文档和索引入口。 |
| `figures/` | 架构图和文档图片。 |
| `frameworks/` | 面向客户端的框架实现和多语言绑定。 |
| `interfaces/` | 公共 Kit（C 接口）和内部 API（C++ 头文件）声明。 |
| `sa_profile/` | 播控系统能力注册配置（SAID=3010）。 |
| `services/` | 播控系统服务核心实现、IPC、适配和配置。 |
| `test/` | 测试资源。 |
| `tools/` | AVSession 管理工具。 |
| `utils/` | 公共工具库（日志、Trace、权限、事件、定时器等）。 |
| `avpicker/` | 投播设备选择 UI 组件（AVCastPicker）。 |
| `avinputcastpicker/` | 通话输入设备投播选择 UI 组件（AVInputCastPicker）。 |
| `avvolumepanel/` | 音量面板 UI 组件。 |

## frameworks

| 目录 | 简要说明 |
| --- | --- |
| `frameworks/common/` | 跨框架公共代码。 |
| `frameworks/cj/` | CJ 语言 FFI 绑定；`include/` 放导出声明，`src/` 放绑定实现。 |
| `frameworks/js/` | JavaScript/N-API 实现。 |
| `frameworks/js/napi/session/` | 会话、控制器、投播控制器、管理器、监听器、回调、元数据、播放状态、队列、媒体描述和投播选择器绑定。 |
| `frameworks/native/` | 原生 C++ 框架实现。 |
| `frameworks/native/session/` | 原生会话客户端代理；`AVSessionManagerImpl` 为管理类门面，回调客户端和监听器客户端实现，版本脚本约束符号导出。 |
| `frameworks/native/ohavsession/` | OHAVSession C++ 封装（`OH_AVSession`/`OHAVSession`/`OHAVCastController`/`OHAVMediaDescriptionBuilder` 等）。 |
| `frameworks/taihe/` | Taihe 绑定；`idl/` 放 IDL，`include/` 放声明，`src/` 放实现。 |

## services

| 目录 | 简要说明 |
| --- | --- |
| `services/etc/` | 服务配置和部署资源（配置文件、启动脚本、参数访问控制、按需启停配置）。 |
| `services/session/` | 播控服务主包。 |
| `services/session/server/` | 系统服务核心实现，承载三大模块（见下表）。 |
| `services/session/ipc/` | IPC 通信（见下"IPC"表）。 |
| `services/session/adapter/` | 外部依赖适配（见下"适配层"表）。 |

### 服务端（services/session/server）

| 目录 | 简要说明 |
| --- | --- |
| 根目录 | 基础播控：`AVSessionService`（系统服务主类）、`AVSessionItem`（会话项）、`AVControllerItem`（控制器项）、`SessionStack`（会话栈）、`FocusSessionStrategy`（焦点策略）、`BackgroundAudioController`（后台音频控制）、`AVSessionUsersManager`（多用户管理）、`AudioDeviceManager`（音频设备管理）、`AVSessionDumper`（调试转储）、`AVSessionWhitelistConfigManager`（白名单）。 |
| 根目录 | 音视频投播：`AVRouterImpl`（投播路由器）、`AVCastProviderManager`（提供者管理器）、`AVCastControllerItem`（投播控制器）、`HwCastProvider`/`HwCastProviderSession`/`HwCastStreamPlayer`（Cast+ 引擎对接）、`HwCastDataSourceDescriptor`/`HwCastDisplayListener`（数据源与显示监听）、`PcmCastSession`（PCM 投播）。 |
| `remote/` | 分布式数据对象同步：`RemoteSessionSource`/`RemoteSessionSourceImpl`/`RemoteSessionSourceProxy`、`RemoteSessionSink`/`RemoteSessionSinkImpl`、`RemoteSessionSyncer`/`RemoteSessionSyncerImpl`、`RemoteSessionCommandProcess`、`RemoteSessionCapabilitySet`、`JsonUtils`。 |
| `softbus/` | 软总线通信：`SoftbusSession`、`SoftbusSessionManager`、`SoftbusSessionManagerDynamic`、`SoftbusSessionProxy`、`SoftbusSessionServer`、`SoftbusDistributedDataManager`。 |
| `migrate/` | 会话迁移：`MigrateAVSessionManager`、`MigrateAVSessionServer`（含 Next 变体）、`MigrateAVSessionProxy`（含 Super 变体）、迁移命令常量、Base64 工具。 |
| `test/` | 服务端单元测试，覆盖会话、控制器、服务、代理、桩、焦点、后台音频、多用户、投播路由/控制器/Cast+、分布式 Source/Sink、软总线、迁移、工具和适配。 |
| `test/fuzztest/` | 模糊测试目标，按适配器、服务、控制器、投播、焦点、后台音频、协同、迁移、软总线、权限、会话监听器划分；每个目标含 GN 目标、测试代码、`project.xml` 和 `corpus/`。 |

### IPC（services/session/ipc）

| 目录 | 简要说明 |
| --- | --- |
| `base/` | IPC 接口定义：`IAVSessionService`、`IAVSession`、`IAVSessionController`、`IAVCastController`、接口码定义、客户端死亡接口。 |
| `idl/` | 回调 IDL：`ISessionListener`、`IAVSessionCallback`、`IAVControllerCallback`、`IAVCastControllerCallback`、`IAncoMediaSessionListener`。 |
| `proxy/` | 客户端代理：服务、会话、控制器、投播控制器代理和客户端死亡代理。 |
| `stub/` | 服务端桩：服务、会话、控制器、投播控制器桩和客户端死亡桩。 |

### 适配层（services/session/adapter）

| 目录 | 简要说明 |
| --- | --- |
| `adapter/` | Ability 连接与管理、账户管理、应用管理（前后台状态）、音频适配（渲染状态、音量、设备、场景）、动态洞察、HiAnalytics 上报、包状态适配、协同管理（HiPlay/URLCasting）、命令发送限流、分布式数据对象适配、扩展连接辅助、按键事件适配、参数配置读取、插件库动态加载、HiCollie 看门狗。 |
